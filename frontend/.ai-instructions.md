# Oya Frontend - AI Agent Instructions

This is the Oya frontend. If you're working on a bead/issue:

## Use Git Isolation When Needed

If a bead needs physical directory isolation, create a Git worktree:
```bash
git worktree add ../<bead-id> <branch>
```

Otherwise, use a normal Git branch and keep bead state in `bd`.

## Working on Oya Frontend Itself

If you're working directly on the ZJJ codebase (not on a bead):

**All build commands must use Moon:**
```bash
moon run :quick      # Format + type check
moon run :ci         # Full pipeline
moon run :test       # Run tests
```

**Never use `cargo` directly** - this project uses Moon for build orchestration.

## Zero-Policy

Oya frontend enforces zero panics and zero unwraps:
- No `.unwrap()`, `.expect()`, `panic!()`, `todo!()`, `unimplemented!()`
- All errors use `Result<T, Error>` with proper propagation
